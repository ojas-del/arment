Pure Pet Food (purepetfood.com) has been analyzed as a reference site.

**Why:** The user is scraping this site's design system, navigation structure, and assets for reference/replication purposes.

**How to apply:** Use this data when comparing project work against the reference site. All design tokens, navigation links, font stacks, and color values are documented here and in the companion extracted-data files.

Key facts:
- Built with Next.js (evidenced by `_next/static/` asset paths and React errors in console)
- Images served from DatoCMS CDN (datocms-assets.com)
- Uses self-hosted fonts: Sofia Pro (body) and Rubik (headings)
- Primary color palette: dark green #274C46, gold/amber #F2A900, purple #5F295E, cream #EAE5DC
- Trustpilot widget embedded via iframe (4.6/5 rating)
- 63+ unique internal page links discovered from homepage
